📥 Cómo obtener el JSON de Webflow
  1. Copy Interceptor (recomendado): Abre el diseñador de Webflow, abre DevTools (F12) y pega esto en la consola (escribe allow pasting primero): 
    window.addEventListener("copy",e=>{let j=e.clipboardData.getData("application/json");if(j){console.log("✅ JSON XscpData copiado");navigator.clipboard.writeText(j)}});
    Luego selecciona una sección en el diseñador, cópiala (Cmd+C), y el JSON se copiará automáticamente. Pégalo aquí.

  2. Exportar sitio: File → Export → Export .zip, extrae el ZIP y abre el HTML
📤 Cómo pegar de vuelta en Webflow
  1. Opción A (recomendada): Presiona el botón "⬇ Pegar en Webflow" y luego haz Cmd+V en el diseñador de Webflow. La herramienta copia el HTML convertido a formato @webflow/XscpData en el portapapeles con el tipo application/json que Webflow necesita. (Puede mostrar "✅ Copiado! Pégalo en Webflow")

  2. Opción B (fallback): Presiona "Copiar HTML" y pégalo directamente en el diseñador con Cmd+V — Webflow convierte el HTML a elementos nativos

  3. Opción C: Agrega un elemento Embed en el diseñador y pega el HTML dentro
¡Copiado!
